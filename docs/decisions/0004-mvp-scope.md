# 0004. The MVP is Milestone B

- **Status:** Accepted
- **Date:** 2026-11-12

## Context

The [roadmap](../../ROADMAP.md) defines three milestones: the core repair loop (A), a feature-complete product (B), and a pilot (C). We need to agree on which one is the minimum worth putting in front of a real firm.

## Decision

The MVP is **Milestone B**: Phases 0–9, covering every capability in the product documents, including estimates, owner approvals, notifications, and reporting. Production readiness (Phase 10) follows before a pilot.

## Consequences

- Milestone A remains an internal checkpoint for reviewing the product, not a release.
- Scope cuts within Phases 7–9 need a new decision rather than an informal change.
