# 0001. Record significant decisions in this log

- **Status:** Accepted
- **Date:** 2026-11-12

## Context

The [roadmap](../../ROADMAP.md) leaves many product and technical questions open until the phase that needs them. Without a written record, the reasons behind each answer get lost, and settled questions get reopened.

## Decision

Record each significant decision as a short numbered file in `docs/decisions/`, added in the same pull request as the change it affects. Decisions are not edited after acceptance; a new record supersedes an old one.

## Consequences

- Every resolved roadmap question gets a decision record.
- Reviewers can check that a pull request matches recorded decisions.
- Small, easily reversed choices do not need a record.
